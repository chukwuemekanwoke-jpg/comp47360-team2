# Sprints

Sprint retrospectives for the TABL project, plus links into the Jira workspace
where the boards, reports and tickets live.

## Jira

The Jira project is **SCRUM** on `table-ucdconnect.atlassian.net`. All three
links need a workspace account — see [Adding people](#adding-people) below if
you get an access error.

| Link | What it's for |
| --- | --- |
| [Sprint burndown chart](https://table-ucdconnect.atlassian.net/jira/software/projects/SCRUM/boards/1/reports/burndown?source=overview) | Remaining work against time for the active sprint — the chart quoted in retrospectives and the final paper |
| [All reports](https://table-ucdconnect.atlassian.net/jira/software/projects/SCRUM/boards/1/reports) | Report index for board 1: burndown, velocity, sprint report, cumulative flow, and the rest |
| [Add people to the workspace](https://table-ucdconnect.atlassian.net/?continue=https%3A%2F%2Ftable-ucdconnect.atlassian.net%2Fwelcome%2Fsoftware%3FprojectId%3D10000&atlOrigin=eyJpIjoiNTA5YmRhMzkzNzc5NDI1MWFlYzAxNDZkODQ2ODlmNGIiLCJwIjoiamlyYS1zb2Z0d2FyZSJ9) | Invite a teammate or assessor to the workspace |

### Adding people

The invite link lands on the workspace welcome screen for project `10000`.
Anyone who needs to read the board — a new team member, a module assessor —
has to be invited before any link above will resolve for them; without an
account they'll hit a login wall rather than the board.
